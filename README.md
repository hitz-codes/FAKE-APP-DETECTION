# Fake App Detection Web Interface

A modern web interface for detecting fake financial apps across PhonePe, Paytm, and GPay platforms.

## Quick Start

### Backend Setup
```bash
pip install -r requirements.txt
cd web_backend
python main.py
```

### Frontend Setup
```bash
cd web_frontend
npm install
npm start
```

Access the web interface at http://localhost:3000

## Features
- Real-time detection dashboard
- Interactive results table with color-coded risk levels
- Evidence generation and viewing
- Takedown email creation
- Manual app analysis

For detailed documentation, see the project files.
